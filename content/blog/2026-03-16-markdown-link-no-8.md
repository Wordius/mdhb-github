An occasional post from [*The Markdown Handbook*](https://md-handbook.com).

Among today’s links are markdown editors Otterly and I Write Like; Defuddle, which gets the main content of any web page in markdown; Kewt, a small as you like static site generator; and Obsidian Web Clipper, which works with any markdown editor, not only Obsidian.

- [Otterly](https://github.com/ajkdrag/otterly) is a local-first, privacy-focused markdown editor. There are no accounts, no cloud dependency and no sync fees. On macOS, Otterly requires Rust, and Tauri, which in turn requires the installation of Xcode. There are different requirements for Windows.
- Get the main content of any page as markdown. [Defuddle](https://defuddle.md) extracts the main content from web pages, removing clutter like comments, sidebars, headers and footers to return clean, readable HTML.
- Did you know you can use [Obsidian Web Clipper](https://obsidian.md/clipper) to copy a page in any markdown editor? Get the contents of a web page by simply clicking the down arrow next to the ‘Add to Obsidian’ button and choosing between the ‘Copy to clipboard’ or ‘Save to file’ options.
- [Kewt](https://git.krzak.org/N0VA/kewt) is a minimal static site generator. Features include no dependencies, support for many embed types, automatic css variable replacement for older browsers, automatic inlining and embedding of many filetypes, inline html support and admonition support.
- [I Write Like](https://iwl.me) is a markdown editor. It allows you to edit and preview markdown in real-time with its live renderer, supports GitHub-flavoured markdown, tables, code blocks and more. Uses AI.
