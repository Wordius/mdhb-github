### The developer says…

This plugin… integrates your academic reference manager with the Obsidian editing experience. [It] supports reading bibliographies in BibTeX/BibLaTeX `.bib` format and CSL-JSON format.

### Features

Citations offers four features:

- Open literature note (⌃⇧O): automatically create or open a literature note for a particular reference. The title, folder and initial content of the note can be configured in the plugin settings.
- Insert literature note reference (⌃⇧E): insert a link to the literature note corresponding to a particular reference.
- Insert literature note content in the current pane (no hotkey by default): insert content describing a particular reference into the current pane. Useful for updating literature notes you already have but which are missing reference information.
- Insert markdown citation (no hotkey by default): insert a Pandoc-style for a particular reference (configure in plugin settings).

You can set up your own template for both the title and content of literature notes using a number of variables.

### Our view

Our main concern is that Citations hasn’t been updated in four years.
