An occasional post[^1] from *[The Markdown Handbook](https://md-handbook.com/)*.

Among today’s links[^2] are markdown editors[^3] Pellet, Lumina and Shoin, an editor for the terminal.

- [Pellet](https://getpellet.app/) is a markdown editor that combines your calendar with tasks. It started as an Obsidian plugin and evolved into the fully fledged markdown editor that’s linked here. It offers a live preview editor where the markdown renders in place with the source underneath, wiki links and backlinks, graph, table and kanban, calendar and Gantt, canvas and whiteboards, PDF and EPUB, and handwriting. This last renders Apple Pencil pages on the iPad. Pencil offers a fourteen-day free trial; thereafter it costs $20 for a lifetime desktop licence, which comes with free mobile apps. Access to AI is by choice. Available for macOS, Windows, Android or iOS (Testflight). 
- [Lumina](https://www.luminaeditor.com/) is a lightweight editor for markdown and plain text files. The app is free to download and open source under the GNU General Public License v3.0. Its developer is VP for a company called Automation Anywhere, “the leader in agentic process automation”; you can imagine how this app was put together. Settings wise, it offers no control over the font, font size or editor width. You can export to html and PDF, and it supports Mermaid diagrams. Available for macOS and Windows.
- [Shoin](https://github.com/nol00p/Shoin) is markdown editor for the terminal. It offers modal editing, live formatting and one centred column of text and nothing else. Works on .md and .txt files only. This is not a code editor.

*Haven’t found what you’re looking for? Try this site’s list of recommended [markdown editors](/markdown-editors).*
