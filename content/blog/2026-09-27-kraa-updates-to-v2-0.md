Web editor [Kraa](https://kraa.io/about) has updated to, well, I don’t know. It’s a web app, so let’s call it v2.0. Where I refer to a leaf below I am using Kraa’s own terminology for a document or file. Among the changes are:

- The UX has been tweaked, giving it a fresh new look.
- A multi-leaf view has been added.
- There’s an explore page to show all public leafs.
- A number of general editor improvements, including adding support for tables or comments.
