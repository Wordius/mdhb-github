An occasional post[^1] from *[The Markdown Handbook](https://md-handbook.com/)*.

Among today’s links[^2] are markdown editors[^3] Margin, Symiosis, Cordelia, Minstrel and Schreibor.

- [Margin](https://gomargin.app) looks like a promising markdown editor, currently in the early stages of development where it remains free for the time being. Open the command palette with the shortcut ⌘⇧O. Format your text using the almost ubiquitous slash command (`/`). Workspaces or spaces can be added in the leftmost sidebar. Subfolders are not recognised, so if you want access to a folder, you’re going to have to add it as a ‘Space’, which could prove unwieldy if you have lots of folders. The developer says he is working to address this for a future release. Wiki links work but there’s no handy popover listing files as you type, so you better remember that filename you were trying to connect to. Tasks work too. Margin gives you control over the font, font size, line height and line length (editor width). Export to markdown, rich text, html or PDF. There are far more themes than necessary for markdown editor in my opinion. AI gets a look in via your own API key or the installation of a local model. Available for macOS
- [Symiosis](https://fasmatwist.com/products/symiosis/) is a free and open source markdown editor inspired by [Notational Velocity](https://www.notational.net/). For many, it will take some getting used to, not least the fact that the notes’ list is always visible above the note being edited, similar to the way messages can be configured to display in email apps, with the message list above and the currently selected message displayed below. One of Notational’s successors, [nvALT](https://brettterpstra.com/projects/nvalt/), had this approach, but it gave you the option of switching to a sidebar layout if you preferred. The other reason that Symiosis may take some getting used to is that it is keyboard driven. But I like this approach. It dispenses with the need for toolbars and formatting bars, and keeps your hands where they should be, on the keyboard. Available for macOS, Linux and Windows.
- [Cordelia](https://cordelia.ink/), available via Testflight, is a single-pane markdown editor. It offers no preview pane, no split view and no rendered view, with the formatting living in the page as you type it. Settings are minimal, allowing you to adjust the font size, line height and enable a spell check. Tabs allow you to switch documents if you want and your export options are to PDF and html. Cordelia is about as barebones as a markdown editor can get, which should appeal to some. Currently free, there is no mention as to whether the developer will request payment at some point in the future. Available for macOS and iOS.
- [Minstrel](https://writewithminstrel.com/) is a place to write books. It allows you to use markdown syntax or a formatting bar. Justified text is what you get, with no option to range left, which would be preferable. The free version gives you the minimal editor experience, with your projects being your own, export to docx, PDF and EPUB, and spell-checking. There are various options for payment, including a $20 lifetime licence, which adds chapter synopses, writing statistics, dialogue analysis, expert reviews and automatic note organisation. Start with the Lite (free) version and see if that fulfils your needs. Available for macOS.

{{ image(path="/img/schreibor.webp", caption="Schreibor does not allow you to adjust the line-length of the editor to a readable width. Looks infinitely worse in full-screen mode") }}

- [Schreibor](https://testflight.apple.com/join/ptrbqH5A), despite sounding like a [piece of furniture](https://en.wikipedia.org/wiki/Schreiber_Furniture) from the 1970s, is a markdown editor. It is available for macOS via TestFlight. There’s no control over line-length (see my views on the [editor width or line length](/blog/the-perfect-markdown-editor-for-writers)). It is built based on the author’s own experience in colloquial and academic writing, rather than as a writer or journalist might consider appropriate. Export to html, print to PDF and publish to Pandoc.
