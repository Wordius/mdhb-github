An occasional post from The Markdown Handbook.

Among today’s links are notes app Tape comes up with a new version, the latest version of Windows 11 is to support markdown through its Notepad app, Lobster.js is a static site generator that weighs in at an almost weightless 22KB, the latest version of MarkEdit introduces YAML frontmatter highlighting, and Collabora clashes with LibreOffice over its plans to revive online.

- Notes app [**Tape**](https://tape.a2n.dev) has come up with a new release that it calls ‘The reader’ version. See it on [GitHub](https://github.com/results-may-vary-org/tape/releases/tag/v3.6.0).
- Windows 11’s [**Notepad**](https://blogs.windows.com/windows-insider/2026/01/21/notepad-and-paint-updates-begin-rolling-out-to-windows-insiders/) is to support markdown.
- [**Lobster.js**](https://hacknock.github.io/lobsterjs/) is a static site generator that uses extended markdown syntax to produce a static website. All it weighs is 22KB.
- Markdown editor [**MarkEdit**](https://github.com/MarkEdit-app/MarkEdit/releases/tag/v1.30.0) introduces YAML frontmatter highlighting and rendering support. Plus they have updated the preview extension for the new capabilities.
- [**Collabora clashes with LibreOffice**](https://www.neowin.net/news/collabora-clashes-with-libreoffice-over-move-to-revive-libreoffice-online/) over a move to revive LibreOffice Online. The Document Foundation, which is behind LibreOffice, has voted to revoke previous decisions and revive its sleeping LibreOffice Online project for those who want to self-host their own alternative to Google Docs or Microsoft 365.
- Ever wanted to find a more straightforward solution than Google Analytics? Here are seven [**European and open source options**](https://www.wordius.com/blog/european-and-open-source-analytics-providers/) for you to try.
