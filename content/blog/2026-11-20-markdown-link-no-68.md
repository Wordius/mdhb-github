An occasional post[^1] from *[The Markdown Handbook](https://md-handbook.com/)*.

Among today’s links[^2] are markdown editors[^3] Lede and Lydie, plus we look at Marked, the markdown viewer built by Brett Terpstra.  

- [Lede](https://www.skeinnotes.app/lede) is a free, native markdown editor for Mac. It renders one page at a time, because that is what it is built to do. You can use Lede in split screen, with the document open on the left and a browser on the right or, alternatively, give your words space to breath in full-screen mode. The choice is yours. You are given the controls to make your article look right, with the font, font size and line length there to adjust in `Settings`. Writing aids can help weed out the complex words and clichés you are prone to reeling off. Defaults to markdown, but the other option is plain text. Handles maths, diagrams and provides a helping hand for tables. There are no themes to talk of, but a simple choice between paper, white, grey and black. By the same developer who brought us [Skein](/blog/markdown-link-no-65/), which I wrote about in an earlier post. Available for macOS.  
- [Marked](https://markedapp.com/), version 3, is a markdown viewer that delivers a markdown preview for Mac. Originally designed as a companion for markdown editor [nvAlt](/blog/2026-10-26-nvalt-lives) (as far as I can remember), it is built by profilic Mac developer [Brett Terpstra](https://hachyderm.io/@ttscoff), the man of a 1000 apps. Terpstra is also expected to deliver [nvUltra](https://nvultra.com/), another markdown editor, which remains in private beta. Marked offers advanced proofreading tools, themes and a number of export options, including to PDF, HTML and DOCX. A number of other export options exist, including EPUB and TextBundle. There are built-in grammar and style checking tools. Works with any text editor. Free trial then it costs £2.99 a month, £29.99 a year or you can take off the child locks for £69.99. Available for macOS.
- [Lydie](https://lydie.co/) is a markdown editor, currently in beta. It is built in Electron. Every built-in feature is a plugin, which is how the app is organised; Lydie’s developer says plugins are not yet a way to extend it. Settings allow you to change the font-size (has no effect I can see) and the line length, but it is yet to allow you to adjust the font or line height, if indeed it eventually offers these choices. In fact, it is the barebones of a markdown editor, because many features, such as the export options, are yet to be added. This is one to come back to in future. There is a companion web app and cloud syncing feature. Available for macOS.
