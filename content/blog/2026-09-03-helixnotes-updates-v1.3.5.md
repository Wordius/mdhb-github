[HelixNotes](https://gitlab.com/ArkHost/HelixNotes/-/releases), the free and open-source, markdown editor first covered on this site in [Markdown Link no. 4](/blog/markdown-link-no-4), has updated to v1.3.5.

The new version brings custom notebook icons, a configurable startup view, markdown syntax highlighting, nested lists, note duplication, improved mobile image tools and new vault maintenance options. It also includes security, accessibility, theme and cross-platform improvements.
