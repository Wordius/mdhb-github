[Autype](https://autype.com/), first covered in [Markdown Link no. 16](http://127.0.0.1:1111/blog/markdown-link-no-16/), has been updated. 

The new rich text editor includes a live final-output preview; forms, signatures, reviews and approvals stay in one place; reusable blocks have been introduced; and you can use the Autype agent or connect compatible AI tools through MCP integration.

There’s also a new price. While it used to cost $24 per month, it’s now down to $5.75 per month, which suggests the developer priced it way too high in the first place.

There is still room for improvement.
