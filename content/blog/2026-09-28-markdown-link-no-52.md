An occasional post[^1] from *[The Markdown Handbook](https://md-handbook.com/)*.

Among today’s links[^2] are markdown editors[^3] Edmund, MarkSchrift and Encribe.

- [Edmund](https://edmund.md/) is a free and open-source markdown editor. Every now and then I come across an app that does things just right. Edmund is one of those apps. The developers have nailed it. It takes a minimal approach, it’s file-based and offers an inline live preview (⌘E). Edmund is for those occasions when you *must* concentrate on your writing. You can hide the toolbar (it is shown in the screenshot above). Tables are supported. It can handle basic maths off the bat plus there’s the ability to add KaTeX support via an extension. Mermaid diagrams are supported in the same way. The one thing that doesn’t appear to work is wiki links. I have asked the developer for a fix. Export is to PDF, html, plain text, rich text or markdown with embedded images. Available for macOS (14 Sonoma or later).
- [MarkSchrift](https://markschrift.com/) is a free markdown editor. The paid side to the app simply adds collaboration ($9.99), which might prove useful for working on team projects. There are settings to control the font and line-length (reading width). Front matter is described in the menu as ‘manifest’; if a document doesn’t have any front matter, you can add it via the manifest command. MarkSchrift has an alternative way of adding tabular data. It certainly beats pipes, colons and equals signs. Export is to PDF, html or Word, and you can use the `Save as` menu item to save a document as markdown or plain text. Available for macOS and iOS (Testflight).
- [Encribe](https://www.encribe.com/)’s website is so busy it gave me a headache. It’s like its developers have been given a magic box and decided to use all the tricks available to them. Either that or they have taken something extra special. They are selling a piece of software that’s supposed to be a quiet space. Encribe claims to ‘keep bots and AI slop away using keystroke biometric verification’. What? The idea with AI is that it has to be invited in, usually, although not always, through the use of a key. Finally, it starts to make sense with: “Encribe gives teachers \[the\] necessary tools to verify authenticity, reducing plagiarism and ensuring academic integrity.” And, eventually, a sense of calm returns with “Write with the simplicity and power of markdown. Style your work using a clean, distraction-free context editor that lets you focus on the words, not the syntax.” Encribe is a word processor; that’s all you need to know. Oh, nearly forgot, it’s not ready yet. You are expected to sign up.
