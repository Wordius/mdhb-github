[Kova](https://kova.md/), the free and open source presentation software first covered in [Markdown Link no . 40](/blog/markdown-link-no-40/), has released v0.7.12.

Updates include:

- Self-contained HTML exporting ([demo](https://kova.md/demo/)).
- Stepped animations for introducing content.
- Built-in support for icon fonts; bundled with Nerd fonts and customisable for other icon fonts, such as Material and Font Awesome, through the themes.yaml config.
- Table of contents custom shortcut offering a similar functionality to Typora.
- Bug fixes and code tidy-ups.

Its developer also announced the release of the Kova Plugin for VS Code. It adds support for Kova’s custom features and syntax to VS Code, plus the ability to launch your presentation from within VS Code; the Kova binary must be present on your machine in order to do this.

The VS Code plugin is in the early stages of development (0.0.1).
