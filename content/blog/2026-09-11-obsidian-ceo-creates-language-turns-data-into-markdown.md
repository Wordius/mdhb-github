Obsidian CEO Steph Ango, also known as [Kepano](https://mastodon.social/@kepano) on Mastodon, has created [Knap](https://knap.md), a new language that turns data into markdown. Knap comes with a syntax that modifies and formats plain text.

Knap is [open source](https://github.com/obsidianmd/knap). It started as the templating language for [Obsidian](https://obsidian.md/). Now any tool can use it. Knap is named after knapping, the process of shaping stones to form arrowheads, scrapers and other tools.

Variables insert values from your data into templates, filters transform values and format markdown, and logic includes content and repeats it over arrays.

It all comes together when you use it to add variables inline with markdown.
