[Plainva](https://plainva.com), the free and open source markdown editor first introduced in this site’s [review](https://blog/review-plainva), has updated to v0.8.0. 

This release addresses the issue of maintaining comment relevance across edits in Plainva. Key points covered by this issue include:

- Comments should persist even if a user’s name changes, requiring a mechanism to link comments to unique identifiers rather than just visible text.
- A new deletion journal ensures that confirmed deletions are propagated across all devices, preventing data from being re-uploaded after a deletion.
- Cryptography for encrypted workspaces requires independent review. As a result, this feature is marked as experimental.
