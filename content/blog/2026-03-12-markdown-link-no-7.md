An occasional post from [*The Markdown Handbook*](https://md-handbook.com).

Among today’s links are: Blogatto, a static site generator; Kirby’s CMS is on sale, again; a piece of software that brings indent mode to markdown; markdown editor Ghostmd; and, Tokie, which transforms your markdown files into a database.

- Static site generator  [**Blogatto**](https://github.com/veeso/blogatto) is a framework for building static blogs with Lustre and markdown. It generates your static site from a single configuration: blog posts from markdown with frontmatter, static pages from Lustre views, RSS feeds, sitemaps and robots.txt. Blogatto has custom components for markdown rendering, configurable blog-post templates, and a dev server with file watching to auto-rebuild and live reload your site.
- [**Kirby’s**](https://getkirby.com/buy) spring sale started this week allowing you to save 20% until 23 March. Better get your skates on.  
- [**Markdown-indent-mode**](https://whhone.com/posts/markdown-indent-mode/) is a small Emacs package that brings org-indent-mode-style visual indentation to markdown files. Whatever floats your boat…
- The [**Reeader**](https://chromewebstore.google.com/detail/reeader-minimal-reader-wi/jblbdklppkompnbobkpncbmbjkaeaeah?hl=en-GB&utm_source=ext_sidebar) extension for Vivaldi – my current browser – is available from the Chrome Webstore. There are many extensions claiming to do the same thing, but I like the look of Reeader. It gets rid of ads and subscription pop-ups, but It also gets rid of images, which I’m less bothered about. I’d be interested to hear which readers you use. [Email me](mailto:info@md-handbook.com) your suggestions, especially if they export to markdown.
- Ever wanted to return to a pure markdown experience, with no preview. [**Ghostmd**](https://mimoo.github.io/ghostmd/) is a native macOS note-taking app with no configuration options. It works well and looks good, but I hate it when developers assume a one-size-fits-all configuration. There’s no control over font size, reading/writing width and bracket pairing, which makes it no good for a crusty old bugger like me with fading eyesight. Even [nvALT](https://brettterpstra.com/projects/nvalt/#dl), that most basic of markdown editors, offers control over these attributes. That said, I do like the fact that Ghostmd is keyboard-first, with Emacs text navigation, a command palette and that it auto-saves every keystroke.
- [**Tokie**](https://tokie.is/introduction) is an interesting, and complicated app to describe. What I will say is that allows you to manage your files like a database if you have that kind of ordered mind, edit notes without opening them, preview websites, and edit code files without an IDE. It’s worth a look.
