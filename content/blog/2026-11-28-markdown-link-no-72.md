An occasional post[^1] from *[The Markdown Handbook](https://md-handbook.com/)*.

Among today’s links[^2] are markdown editors[^3] WriteRoom and Moped (it’s faster than it sounds). Outliners get a look in in the form of Zavala, a free and open source tool with a truckload of features.

- [WriteRoom](https://www.hogbaysoftware.com/writeroom/) is a markdown editor built by Jesse Grosjean. Known for such popular apps as TaskPaper and FoldingText, Grosjean has been making Mac apps since 2004. He specialises in writing tools, and it shows in WriteRoom, a single page editor. Settings allow you to adjust the font, font size, line height and editor width. There’s no table builder, but there is a setting (`Markdown > Align as you type`) that gives you the next best thing. Settings is also where you get the opportunity to choose your markdown flavour: original markdown or CommonMark. The document tree is missing, as expected, but if there’s one feature I would like to see added to a single-pane editor it is tabs. That would allow you to open, say, 10 documents at a time, introducing the possibility of opening an entire book or just a couple of notes, one you are working on and one for research or notes. It would save a lot of time when switching to the Finder every time you have to check an important fact. Costs $29.99 after a 14-day free trial. Available for macOS.
- [Moped](https://github.com/RobertoMachorro/Moped), in spite of what the name suggests, is a fast and free text editor. Choose from any of around 30 programming languages, including markdown, and eight themes. Adjust the font and font size to suit. Moped opens a single document at a time, so there’s no document tree to distract you. The single window and simple set of settings belies the fact this is a powerful editor. Think of it as a step up from TextEdit, although TextEdit wins when it comes to setting a character limit on the width a document spans, allowing you to set a comfortable reading width. Available for macOS.
- [Zavala](https://zavala.vincode.io/) is a free and open source outliner. Features are many: lock and encrypt outlines; sync outlines using iCloud with full offline editing; share outlines with one or more other Zavala users; use the web clipper extension to import web pages; embed images in text fields; customise the fonts; build custom shortcuts using actions; tag outlines and a tag search is automatically generated in the sidebar showing related outlines; open any outline by typing a portion of the name into the Open Quickly dialog; do a full text search; search for text; mark items as complete; and everything has a keyboard shortcut to make you more productive. Imports from OPML, markdown and HTML files, and exports to the same range of file types. Available for macOS or iOS.
